BOIPELO KEIKELAME — DANCE PORTFOLIO WEBSITE

This is a responsive, one-page static website. It can be hosted for free on Netlify or GitHub Pages.

BEFORE PUBLISHING
1. Open index.html in a browser to preview.
2. Replace the hero photo placeholder and gallery blocks with your own dance photographs. (The current coloured blocks are intentional placeholders.)
3. Replace YOUR-EMAIL@example.com in index.html with your professional email address.
4. Check all experience dates and descriptions, then edit any details you want changed.

FREE PUBLISHING WITH NETLIFY DROP
1. Create a free account at https://app.netlify.com/drop
2. Extract this ZIP file on your computer.
3. Drag the extracted folder named boipelo-dance-portfolio onto the Netlify Drop page.
4. Netlify will publish the site and provide a public URL. You can change the site name in Netlify site settings.

No paid domain is required. The free URL will use a netlify.app address.
